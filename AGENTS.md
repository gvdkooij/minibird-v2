# MiniBird v2
Python 3.12+, FastAPI, SQLite, Jinja2, minimal vanilla JS. Use this existing isolated checkout; do not create worktrees unless requested.
Install: python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
Validate: .venv/bin/python -m pytest -q; .venv/bin/pip check.
Start local: sh scripts/dev.sh. Never publicly expose development setup.
Use integer cents and Decimal half-up rounding per line. Keep issued documents and customer/company snapshots immutable. Number gaps are intentional; never reuse identifiers. Every mutating request must require a valid session CSRF token. Never send live SMTP messages from tests. Never log passwords, cookies, tokens or customer details. Back up SQLite and preserve MINIBIRD_SECRET before upgrades. Do not touch gvdkooij/minibird.
Importers: keep uploaded personal data out of Git fixtures; use synthetic exports. Imported financial documents are immutable and retain original PDFs and declared UBL totals/tax subtotals. Never recompute historical VAT cents using the native-document calculation. ZIP/XLSX/XML parsing must remain bounded and must never extract archive paths or resolve external entities. Current database schema is 3; migration and import must be atomic. Preserve preview/CSRF/session isolation and repeat-upload idempotency.
Uploads support 50 MiB archives via authenticated 512 KiB pieces. Keep CSRF and ownership checks on every upload operation, ordered/idempotent chunk writes and cleanup of assembled/aborted uploads. Sessions use SameSite=Lax for Codespaces authentication returns; never remove CSRF checks to fix stale forms.
Use the namespaced minibird_session cookie. Do not fall back to another service’s generic session cookie. Keep authentication-failure reason codes free of secrets and distinguish app responses from unverified proxy errors.
